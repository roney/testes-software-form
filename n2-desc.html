🧪 Atividade Prática - Teste de Sistema

Nesta atividade você atuará como um testador de software. Seu objetivo é analisar o sistema de Reserva de Hotel disponibilizado pelo professor, criar casos de teste, executar os testes e documentar possíveis problemas encontrados.

Importante:
Esta atividade deve ser respondida em papel e entregue ao professor ao final da aula.

Parte 1 – Identificar Funcionalidades

Explore o sistema e liste pelo menos 5 funcionalidades que podem ser testadas.

Exemplo:
Verificar se o sistema valida corretamente um campo obrigatório.

Escreva suas funcionalidades identificadas no papel.

Parte 2 – Criar Casos de Teste

Crie no mínimo 5 casos de teste.

Cada caso de teste deve conter:

  • ID do teste
  • Cenário
  • Dados de entrada
  • Resultado esperado
Exemplo:
ID Cenário Dados de Entrada Resultado Esperado
CT00 Campo obrigatório vazio Campo não preenchido Sistema exibe mensagem de erro

Parte 3 – Executar os Testes

Execute os casos de teste criados.

Para cada caso registre:

  • Resultado obtido
  • Status (Passou ou Falhou)

Parte 4 – Reportar Bugs

Caso algum teste falhe, registre um relatório de bug contendo:

  • Título do bug
  • Passos para reproduzir
  • Resultado esperado
  • Resultado encontrado
  • Severidade (Baixa, Média ou Alta)
Exemplo:
Título: Campo obrigatório não validado.

Critérios de Avaliação

  • Identificação correta das funcionalidades
  • Qualidade dos casos de teste
  • Execução dos testes
  • Qualidade dos relatórios de bug
  • Organização da resposta
Entrega: atividade individual, respondida em papel e entregue ao professor ao final da aula.
